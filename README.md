# Solar Oak

Pagina di presentazione e raccolta richieste per Solar Oak, iniziativa in fase di costituzione.

HTML, CSS e JavaScript senza dipendenze frontend. Font e immagini locali. GitHub Pages.

Percorso: rendimento del parco → cura quotidiana e controllo dei dati → vantaggi per la proprietà → RoboClean / Insight / Triage AI → ruolo di Solar Oak → valutazione del sito → FAQ → contatto.

Modulo temporaneamente disabilitato in attesa della conferma del servizio di inoltro. Il contatto email resta disponibile. Nessun analytics o pixel pubblicitario. Non inserire chiavi private nel sito.

Le immagini sono illustrative: nessun robot proprietario, dato operativo, documento riservato o risultato fisico non validato.
