# Solar Oak

Sito istituzionale del progetto Solar Oak: robotica e dati per il fotovoltaico a terra.

HTML, CSS e JavaScript senza dipendenze. Font e immagini sono ospitati localmente.

La presentazione pubblica contiene informazioni generali. Non include documentazione tecnica riservata, rappresentazioni del robot o accessi alla piattaforma operativa.

Il sito è pubblicato tramite GitHub Pages.
