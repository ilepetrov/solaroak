# Solar Oak

Pagina di presentazione e raccolta richieste per Solar Oak, iniziativa in fase di costituzione.

HTML, CSS e JavaScript senza dipendenze frontend. Font, immagini e video locali. GitHub Pages.

Percorso: esigenza del proprietario → vantaggi → RoboClean / Insight / Triage AI → stato dello sviluppo → primo confronto → FAQ → modulo.

Modulo temporaneamente disabilitato in attesa della conferma del servizio di inoltro. Il contatto email resta disponibile. Nessun analytics o pixel pubblicitario. Non inserire chiavi private nel sito.

Immagini e video sono illustrativi: nessun robot proprietario, dato operativo, documento riservato o risultato fisico non validato.
